SHYAMA PUJA WEBSITE — MATTE BLACK / RED REDESIGN

WHAT CHANGED
- Reworked the existing design into a matte-black, minimal layout.
- Changed action buttons to light red with deep-maroon hover states.
- Added restrained 3D depth to cards, schedule panels, support blocks and gallery tiles.
- Removed decorative glow/slope effects, ornamental rules, emoji-like symbols and arrow decorations.
- Preserved the existing page sections, schedule rendering, gallery lightbox, developer modal and social links.
- Kept the existing vanilla HTML/CSS/JavaScript setup; no npm or build step is required.

RUN
1. Extract the ZIP.
2. Keep index.html, styles.css, script.js, event-data.js and assets/ together.
3. Open index.html in a browser, or use VS Code Live Server.

NOTES
- The assets folder is included so the supplied cover, leaflet pages and developer portrait display correctly.
- To replace images later, keep the same filenames or update their paths in event-data.js / index.html.
- Existing event text and schedule data were retained; this update focuses on the requested visual redesign.
